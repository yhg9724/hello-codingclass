# 1. 회사 코딩반 1회차(AI스터디)

회사 코딩반 1회차와 AI 스터디를 함께 관리하는 프로젝트입니다.

## 서버

```powershell
npm install
npm run dev
```

기본 주소: `http://127.0.0.1:5101`

## 하위 번호

- 1-1. 수업 실습
- 1-2. AI 스터디 정리
- 1-3. 과제/복습

## 기술 스택

- React
- Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.
